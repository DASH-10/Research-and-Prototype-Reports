# Research and Prototype Reports

A curated collection of academic research and prototype documentation. This repository preserves projects whose main evidence is a written report, design process, user analysis, or practical reflection rather than a standalone software codebase.

## Collections

### Prototypes

#### Campfire — Human-Computer Interaction Prototype

[Read the Campfire HCI Prototype Report](prototypes/campfire/Campfire-HCI-Prototype-Report.pdf)

Campfire is a mobile community concept designed to help university students find study partners, build academic connections, and join focused groups. The report covers:

- the problem statement and project goals;
- user questionnaires and needs analysis;
- competitor analysis;
- functional and non-functional requirements;
- high-fidelity mobile interface designs;
- conclusions and possible future improvements.

### Research

#### Webots Practical Work Reflection

[Read the Webots Practical Work Reflection Report](research/webots/Webots-Practical-Work-Reflection-Report.pdf)

This report documents practical robotics and simulation work completed with Webots. It explains lessons learned while building and controlling simulated robots, including:

- creating a Webots world and adding objects;
- using C language controllers;
- understanding nodes, fields, motors, and sensors;
- solving movement, obstacle-avoidance, and physics problems;
- using supervisor controllers;
- reflecting on skills gained and future learning goals.

## About the documents

These reports are preserved as portfolio evidence of research, design, analysis, and practical learning. They may include academic formatting, institutional branding, and named contributors or instructors from the original submissions.

The documents describe educational or prototype work. They should not be interpreted as production-ready products, formal scientific publications, or professional advice.
